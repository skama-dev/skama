# Getting support

Skama is in early development and maintained by volunteers, so there is no guaranteed response time. These are the right places to get help:

- **Questions and ideas:** start a discussion in [GitHub Discussions](https://github.com/skama-dev/skama/discussions). Use the Q&A category for questions, so that answers can be marked and found later.
- **Bugs and feature requests:** open an issue using one of the [issue forms](https://github.com/skama-dev/skama/issues/new/choose).
- **Security vulnerabilities:** never open a public issue. Follow the [security policy](SECURITY.md).
- **Code of conduct concerns:** email conduct@skama.org, as described in the [code of conduct](CODE_OF_CONDUCT.md).

Please search existing discussions and issues before opening a new one.
